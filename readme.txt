Widget Elementor per caroselli di card da repeater JetEngine, da contenuto statico o da sole immagini.

== Description ==

Carosello a scorrimento orizzontale nativo (scroll-snap, swipe, trackpad) con card di testo, icone, pulsanti e immagini di sfondo, oppure di sole foto. Frecce in sei posizioni, indicatori di posizione, scorrimento infinito, autoplay, animazioni d'ingresso e hover.

La documentazione completa è nel file DOCUMENTAZIONE.md incluso nel plugin.
